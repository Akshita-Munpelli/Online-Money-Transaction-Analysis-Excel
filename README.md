## Project Overview
The Online Money Transaction Analysis Dashboard is an interactive Excel dashboard designed to analyze digital payment transactions and identify trends across states, transaction types, and payment performance.

## Project Objective
- Analyze digital payment transaction trends.
- Compare transaction performance across states.
- Identify high-performing transaction categories.
- Track transaction volume and transaction value.
- Create an interactive dashboard for easy business analysis.

## Key KPIs
- Total Transactions
- Total Transaction Amount
- Total cashback
- success Rate
- Suspected Fraud
